🌐 Sainyx API

Call Sainyx from a terminal, backend, or HTTPS client.

1. Your HTTPS base URL
Loading URL...
This URL is the current Sainyx Space address. Keep /api/v1 at the end.
2. Create the server key
python -c "import secrets; print(secrets.token_urlsafe(32))" Hugging Face Space: Settings → Secrets and variables → New secret Name: SAINYX_API_KEY Value: paste the generated key
The API key is created by you, not by the Hugging Face token. Never put it in public frontend code.
3. Check the server
curl https://your-space.hf.space/api/v1/status
Status is public and reports whether text, image, video, and voice are available.
4. Call the generation API
curl -X POST https://your-space.hf.space/api/v1/generate \ -H "X-API-Key: your-generated-key" \ -H "Content-Type: application/json" \ -d '{"type":"voice","text":"Hello from Sainyx"}'
The response contains audio_base64 for voice, image_base64 for image/video, and text for text.
5. PowerShell alternative
$headers = @{ "X-API-Key" = "your-generated-key" } Invoke-RestMethod -Method Post -Uri "https://your-space.hf.space/api/v1/generate" -Headers $headers -ContentType "application/json" -Body '{"type":"voice","text":"Hello from Sainyx"}'
Available types
textimagevideovoice
Video requires a trained video checkpoint. Voice works without a trained model. The Space must be running and public for colleagues to reach it.
