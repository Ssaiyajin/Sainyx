🌐 Sainyx API

Call Sainyx from a terminal, backend, or HTTPS client.

1. Your HTTPS base URL
Loading URL...
This URL is the current Sainyx Space address. Keep /api/v1 at the end.
2. Create the server key
python -c "import secrets; print(secrets.token_urlsafe(32))" Hugging Face Space: Settings → Secrets and variables → New secret Name: SAINYX_API_KEY Value: paste the generated key
The API key is created by you, not by the Hugging Face token. Never put it in public frontend code.
3. Check the server
curl https://your-space.hf.space/api/v1/status
Status is public and reports whether text, image, video, and voice are available.
4. Call the generation API
curl -X POST https://your-space.hf.space/api/v1/generate \ -H "X-API-Key: your-generated-key" \ -H "Content-Type: application/json" \ -d '{"type":"text","prompt":"Who is Goku?","max_tokens":80,"seed":1234}'
JSON results use a shared type, status, and result envelope. Use response_format: binary for a direct PNG or WAV download.
5. PowerShell
$headers = @{ "X-API-Key" = "your-generated-key" } Invoke-RestMethod -Method Post -Uri "https://your-space.hf.space/api/v1/generate" -Headers $headers -ContentType "application/json" -Body '{"type":"text","prompt":"Who is Goku?","max_tokens":80,"seed":1234}'
6. Long-running requests
Set async: true to receive a job ID and status/result URLs. Poll the status URL with the same API key, then fetch the result when complete. Jobs are kept in memory for up to one hour.
Available types
textimagevideovoice
Limits: 64 KiB/request and 60 generation requests/minute/IP. Image prompts are metadata only; video is one PNG frame; voice currently returns a tone demo, not speech. OpenAPI specification
